# 04 · Codex 工程化接手说明

## 本轮交付的位置

本包已将输入几何、相对映射、机械臂 FK/微分 IK、交互监督和离线回放做成可运行参考。它不是占位伪代码，但它也没有接摄像头或电机。先完整阅读 01、02、03、05、07，不要只看几个函数就跳过边界。

## 阶段 A：复现和定位，不重写检测器

在独立 vision 环境运行官方 `example/vector_retargeting`。使用原始、未裁剪、未镜像图像，核实 RGB 顺序与 handedness。先不接机器人，不改变默认关键点数，也不加自定义角度门限。

录制相同动作：自然手掌、指尖向下、侧掌、张合、旋转、前后移动、短遮挡和重新出现。保留全部帧、检测失败和模型输出。用 `examples/upstream_probe.py` 或等价录制适配器获取基线；该工具的时间为主机读帧时刻，接实时控制前必须换成经过验证的采集时间。

交付结果必须区分：未检测到、左右手选错、局部点有效但全局平移缺失、深度无效、融合拒绝、控制暂停。没有这些数据前不换模型，不宣称“AnyTeleop 已经解决识别率”。

## 阶段 B：RGB-D 输入与全局手腕

以已有 D455 为推荐第一验证设备，不把它当作用户已确认的最终唯一相机。若本地实际采用其他 RGB-D，保持相同接口。相机硬件驱动负责 RGB/深度映射、内参、畸变、单位和采集时间。

保留上游朝向，接入本包平移融合器作为 A 路。完整录像上验证静态抖动、真实位移、只旋转时的位置漂移、拇指开合时的位置漂移。B 路可以用可信掌点 3D 配准或其他上游全球手部估计器，必须使用同一批录像比较。

只有一个掌点有效时，不把深度填洞或历史预测冒充多点几何验证。模型点/深度点/表面点的来源需要保留。多视角是解决可见性的后续选择，不先恢复旧的复杂双目工程。

## 阶段 C：官方模型上的仿真与控制语义

下载官方 **SO101 follower** 的完整 URDF 与所有引用 mesh。不要用 leader、SO100 或自画的夹爪替代。按关节名构建链，配置真实固定 TCP；显示 mesh 必须使用 visual.origin。

先运行无硬件 3D 预览，输入使用完整实拍的观测回放。三个平移轴、整体旋转、开合、松开重接管分别能看到“期望目标—机器人实际可达目标”的差异。SO101 全 6D 不可达时显示姿态误差，不能通过偷偷移动位置来掩盖。

将用户已有运动学/控制模块与参考实现对照；有成熟实现可复用，不要求替换成本文的小型 URDF 解析器。必须保留同样坐标约定、控制语义和回归用例。

## 阶段 D：运动后端和真机适配

cuRobo 路线：固定具体 tag/commit 与依赖；跑通官方 Reactive Control；导入全 URDF 与 mesh；建立 collision spheres、自碰撞忽略表、桌面模型；明确五轴位置/姿态任务优先级；验证动态目标刷新与不可达处理。接口为 `MotionBackend`，不硬编码旧 `MpcSolver` API。

若 CPU servo 已满足受限桌面 demo 的体验目标，也可保留 CPU 后端，但**真实碰撞守卫仍必须有**。简化关节限位不能冒充避障；只检查末端高度不能发现肘部碰桌。

复用现有 LeRobot/ROS 驱动，由唯一 robot-worker 持有串口。按名称标定 driver 单位、符号、零位、实际关节限位。真实 gripper 标定与腕 roll 范围也需验证。禁止把归一化 LeRobot 数值当成 URDF 弧度。

实现与 UI/识别独立的本地 watchdog：过期命令、上游断线、异常退出和 PAUSED 都触发受控停止。命令包含有限有效期。是否保持 torque、如何停止和保护负载，要在驱动层实测确认，不能统一关闭 torque。

## 阶段 E：完整任务验收

按 05_ACCEPTANCE 记录完整视频、日志和独立位移测量。验证用户自然的指尖向下姿态；不得通过挑好帧、减少姿态范围或把预测当作测量通过验收。至少完成抓取、搬运、放置的完整回合，而非只在空中展示末端追踪。

## 必须回报的工程决策

每个 PR/提交写清：复用上游版本；新增哪些适配；是否改变输入坐标；通过了哪些数值/录像/仿真/真机测试；仍未验证什么。任何门限改变都要列出前后完整会话指标。

不要改动原用户仓库的串口控制所有权、已有公共协议或系统环境，除非任务明确授权。将旧 handtrack v1/v2 接入作为兼容工作，不把失败的旧算法默认带回主线。

## 可直接给 Codex 的起始任务

> 阅读本仓库 README、AGENTS.md 和 docs 全部文档。目标是以 AnyTeleop 的“腕部控制末端、手指控制夹爪”分层路线实现 SO101 遥操作，而不是人体关节角复制。先运行测试与离线回放，确认交付件基线。随后检查我的本地现有工程，列出可复用的相机、运动学和驱动模块；不要立刻连接电机。第一轮仅完成原版 dex-retargeting detector 的完整帧录制/诊断、RGB-D 手腕观测适配以及无硬件回放验证，保持独立虚拟环境。保留全部21点，明确深度/模型/预测来源，拒绝把局部腕点当全局坐标。对用户自然指尖向下姿态保留完整评估。每阶段交付代码、复现命令和真实测试结果。真机写入功能必须在明确的硬件放行任务中单独实现。
